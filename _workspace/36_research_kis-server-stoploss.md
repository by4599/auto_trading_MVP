# 36_research — 한투 서버 자동 손절(STOP) 주문을 우리 앱이 쓸 수 있나

> 2026-10-10(토) 01:40경 KST · 리더 · 사용자 요청("한투 증권사 서버가 대신 손절해 주는 기능이 있는지 확인").
> 배경: A동은 며칠씩 보유하는데 손절·트레일링 감시가 앱(노트북) 안에서만 돈다. 10-06~10-08처럼 PC가 잠들면 손절도 멈춘다.

## 0. 결론

**기능은 있다(HTS·MTS 화면). 그러나 우리 앱이 쓰는 Open API로는 쓸 수 없다.** 그래서 "앱이 꺼지면 손절이 멈춘다"는
문제를 이 기능으로 자동 해결할 수는 없다. 근본 해결은 여전히 항상 켜진 실행 환경이다.

## 1. 한투 "주식 서버자동(STOP)주문" — 있다

출처: 한국투자증권 HTS 도움말 [8251] 주식StopLoss — http://truefriend.com/pro_help/8251.html (2026-10-10 조회)

- 손절매(Stop Loss) · 이익실현 · 이익제한(Trailing Stop) 조건을 **증권사 서버에 저장** → "HTS를 종료하더라도 조건이 성립되면
  자동으로 주문" ('자동주문' 모드일 때. '수동주문' 모드는 HTS가 켜져 있어야 한다)
- 감시 최장 30일 · 수수료 없음 · SMS 통보 · 복수 계좌 감시 가능 · 보유 잔고 일괄 조건(손익 %, Tick)도 가능
- 한계:
  - 발동 후 일부만 체결돼도 나머지 수량은 다시 감시하지 않는다(장 종료 시 감시 종료)
  - 권리락·배당락·액면분할·감자 등 기준가가 바뀌는 종목은 그날 08:00에 감시가 강제 중지된다(SMS 통보)
  - 03:00~04:00 접수 제한, 비밀번호를 바꾸면 저장된 조건으로는 주문이 나가지 않는다
  - 시간외·동시호가 예상체결가는 감시 조건이 되지 않는다
- **모의투자 계좌에서도 되는지는 확인하지 못했다.**

## 2. Open API에는 없다

출처: 한투 공식 저장소 `koreainvestment/open-trading-api`의 `examples_llm/domestic_stock` (API 156개, 2026-10-10 조회)

- 주문 계열은 `order_cash`(현금) · `order_credit`(신용) · `order_rvsecncl`(정정취소) · `order_resv` / `order_resv_ccnl` /
  `order_resv_rvsecncl`(예약주문)뿐이다. **스탑·감시·가격 조건 발동 주문 API는 없다.**
- 주식예약주문 [v1_국내주식-017] (`/uapi/domestic-stock/v1/trading/order-resv`, tr_id `CTSC0008U`)은 **시간 예약**이다.
  15:40~익영업일 07:30에 접수해 다음 영업일 장 시작 때 보내거나(일반), 종료일까지 매 영업일 보낸다(기간, 최대 30일).
  주문구분은 지정가·시장가·조건부지정가·장전 시간외뿐이고 "가격이 얼마가 되면 낸다"는 조건이 없다.
- 지정가 매도를 손절가에 걸어 두는 식으로 흉내 낼 수도 없다 — 현재가보다 낮은 지정가 매도는 장 시작 즉시 체결된다.

## 3. 선택지

| 방법 | 내용 | 평가 |
|---|---|---|
| 사람이 HTS/MTS에서 서버 손절을 직접 걸기 | 보유 종목마다 손절선을 화면에서 등록 | 앱의 손절과 겹쳐 두 번 매도될 수 있다(두 번째는 수량 부족으로 거부되겠지만 앱 장부 대사가 꼬일 수 있다). A동은 종목·손절선이 자주 바뀌어 손으로 맞추기 어렵다. **앱이 오래 꺼져 있을 때의 임시 안전망**으로만 쓸 만하다. 모의투자 지원 여부 미확인 |
| 항상 켜진 컴퓨터로 이전 | 앱의 손절·트레일링 감시가 끊기지 않게 | 근본 해결. 대시보드를 밖에 노출하면 OPERATIONS §6 인증 요건이 먼저다 |
| 꺼짐 알림(하트비트) | 앱이 멈추면 사람이 바로 알게 | 손절을 대신하지는 않지만 대응 시간을 줄인다. 오늘 바로 가능 — `HEARTBEAT_URL`만 넣으면 된다(`DeadmanHeartbeat.java:61-63`, 지금은 미설정이라 한 번도 보낸 적이 없다) |

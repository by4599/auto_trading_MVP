# 투자 판단 방법론 — 종목 발굴 · 목표가 · 손절가 산정의 근거

> 이 문서는 "전문 투자자·증권사는 무슨 근거로 종목을 고르고 목표가·손절가를 정하는가"를
> 정리하고, 그중 **자동화 가능한 것**을 골라 이 시스템의 단계별 목표로 매핑한다.
> README의 Phase 3(뉴스 → 투자 방향)의 상위 설계 문서다.

비유하면: 지금 시스템의 "뉴스 수집"은 요리로 치면 **장보기만 하는 단계**다.
전문가들은 장보기(정보 수집) → 레시피 선정(종목 발굴 프레임) → 계량(목표가/손절가 산정)
→ 맛보기(검증/백테스트)까지의 전 과정을 갖고 있다. 이 문서가 그 레시피 전체를 정의한다.

## 0. 기본 매매 규칙 카드 — 한눈 요약

| 항목 | 규칙 | 출처(계보) |
|---|---|---|
| **진입** | 당일 가격 > 시가 + (전일 고가−저가) × K=0.5 | 래리 윌리엄스 (최우선) |
| **투입 한도** | 총자산의 30%(Sleeve B) · 종목당 10% | ADR-001 / 프랍 데스크 표준 |
| **주문 수량** | 1R(계좌 1% 손실) ÷ 손절폭으로 역산 — 항상 내림, 왜곡 ±20% 초과 시 스킵 | 반 K. 타프 (R-멀티플) |
| **손절** | 체결가 − ATR(14) × 1.5~2.0 (체결가 기준 재계산) | 터틀 트레이딩 / 와일더 |
| **청산** | 15:15 타임컷 전량 (부분 익절 미채택 — 트레일링은 A/B 검증 후) | 래리 윌리엄스 (당일 청산) |
| **손익비** | 당일 돌파 = 전략 단위 관문 / 이벤트 = 건별 `RiskRewardRule` (§4.4 층위 분리) | 반 K. 타프 |
| **주문 방식** | 지정가 분할(Price Jitter) — 시장가 금지 | ADR-001 2.5 |
| **계좌 방어** | 일일 −3% 신규중단 / −5% 강제청산 / MDD 10% 전면중단 | 헤지펀드 표준 리스크 관리 |

> ⚠️ K=0.5, ATR 계수, 손익비 2.0은 **B-3 백테스트 소급 검증 전의 잠정값**이다.
> 진입 시간 창·거래량·트레일링·지수 필터 4종은 훅만 구현하고 기본 OFF —
> [백테스트 §3.3](BACKTEST-DESIGN.md) A/B에서 이긴 것만 켠다.

## 1. 정보 수집 계층 — 전문가들이 실제로 보는 것

뉴스는 여러 정보원 중 하나이며, 그것도 **가장 늦은 축**에 속한다.
정보의 신뢰도·속도 순으로 정리하면:

| 우선순위 | 정보원 | 내용 | 특성 |
|---|---|---|---|
| 1 | **공시 (DART)** | 실적, 단일판매·공급계약(수주), 유상증자, 자사주, M&A, 최대주주 변경 | 법적 책임이 있는 1차 정보. 가장 신뢰도 높음. Open API 제공 |
| 2 | **수급 데이터** | 외국인/기관 순매수, 공매도 잔고, 프로그램 매매 | "돈이 실제로 어디로 가는가". KIS API로 조회 가능 |
| 3 | **매크로 지표** | 기준금리, 환율, 유가, 미국 국채금리, 반도체 업황 지표(DRAM 현물가 등) | 섹터 전체의 방향을 결정 |
| 4 | **정책/규제** | 정부 예산·보조금, 수출 규제, 산업 육성책 | 발표 시점이 명확한 이벤트 — 자동 감지에 적합 |
| 5 | **증권사 리포트 컨센서스** | 목표가, 투자의견, 실적 추정치(EPS 컨센서스)의 **변화** | 절대값보다 상향/하향 방향이 신호 |
| 6 | **뉴스** | 위 1~5가 기사화된 2차 가공물 + 돌발 이벤트 | 가장 빠르게 접할 수 있으나 노이즈 최다 |

**핵심 교훈**: "미국 반도체 수출 제한" 같은 뉴스가 왔을 때 전문가가 보는 것은 기사 자체가
아니라 ① 이게 어떤 **이벤트 유형**인지 ② 어느 **밸류체인**에 어느 방향으로 작용하는지
③ 과거 유사 이벤트에서 주가가 **실제로 어떻게 반응했는지**다.

### 이벤트 유형 분류 체계 (시스템이 채택할 택소노미)

```
이벤트 = { 유형, 방향(+/-), 강도, 대상(종목/섹터/밸류체인), 지속성(단발/구조적) }

유형 예시:
  실적    : 어닝 서프라이즈/쇼크, 가이던스 상향/하향
  수주    : 대규모 공급계약, 수주 취소
  정책    : 보조금 확대/축소, 규제 신설/완화, 관세
  산업    : 원자재 가격 급변, 경쟁사 감산/증설, 기술 전환
  기업행동: 자사주 매입/소각, 증자(악재), 배당 확대, M&A
  거버넌스: 최대주주 변경, 소송, 회계 이슈
```

## 2. 종목 발굴 — 4가지 표준 접근법

### 2.1 Top-down (증권사 전략팀 방식) — 이 시스템의 주력 후보

매크로/정책 → 수혜 섹터 → 밸류체인 → 종목 순으로 좁혀 내려온다.

```
예: "정부 전기차 보조금 확대" 발표
  → 섹터: 2차전지
  → 밸류체인: 완성차(현대차) < 셀(LG엔솔) < 소재(에코프로비엠) < 장비
     (일반적으로 밸류체인 하류일수록 이익 레버리지가 커서 주가 탄력도 큼)
  → 종목: 재무 필터(아래 2.2) 통과분만 후보 등록
```

자동화 관점: **이벤트 유형 → 밸류체인 매핑 테이블**을 사전 구축해 두면
뉴스/공시가 왔을 때 후보 종목군을 기계적으로 뽑을 수 있다. 이것이 Phase 3의 핵심 산출물.

### 2.2 Bottom-up (재무 스크리닝) — 후보군 필터로 사용

발굴이 아니라 **탈락**시키는 용도로 쓴다. 아무리 테마가 좋아도 아래를 통과 못 하면 제외:

| 필터 | 기준 예시 | 이유 |
|---|---|---|
| 수익성 | ROE > 8%, 영업이익률 흑자 | 적자 기업은 테마가 꺼지면 급락 |
| 재무 안정성 | 부채비율 < 200% | 증자(주주가치 희석) 리스크 |
| 유동성 | 일평균 거래대금 > 일정액 | 자동매매 체결 가능성 (슬리피지) |
| 밸류에이션 | 섹터 평균 대비 PER/PBR | 이미 다 오른 종목 배제 |

### 2.3 Event-driven (이벤트 통계) — 백테스트로 검증 가능한 유일한 방식

"이 유형의 이벤트가 발생하면 D+1 ~ D+20에 평균 몇 % 움직였나"를 과거 데이터로 통계 낸다.
전문 헤지펀드의 표준 방식이며, **자동매매 시스템과 가장 궁합이 좋다** —
규칙이 명확하고, 진입·청산 타이밍이 이벤트 시점에 고정되기 때문.

### 2.4 Quant Factor (팩터 스코어링) — 장기 확장 방향

모멘텀(추세), 밸류(저평가), 퀄리티(수익성), 수급(외국인 매수) 팩터를 점수화해 합산.
ADR-001의 `MINIMUM_QUALITY_THRESHOLD` · Capacity Scaling 랭킹이 바로 이 자리에 들어간다.

### 2.5 유니버스(워치리스트) 관리 — 누가 언제 종목을 넣고 빼는가

발굴 이전에 "후보가 될 자격이 있는 종목의 풀"을 규칙으로 관리한다:

- **편입 조건**: §2.2 재무 필터 전부 통과 + 일평균 거래대금 하한 충족 + 이벤트 매핑
  테이블(§2.1)에 밸류체인 소속이 정의된 종목
- **제외 조건**: 관리종목/거래정지 지정 즉시, 재무 필터 탈락 시 다음 월간 갱신에서
- **갱신 주기**: 월 1회 정기 + 대형 이벤트 발생 시 수시 (편입은 사람 승인, 제외는 자동)
- **상한**: 워치리스트 최대 20종목 (1초 루프의 API 호출 한도와 감시 품질의 상한)

### ⚠️ 리딩방/유튜브 방식에 대한 입장

리딩방·유튜브의 "추천"은 방법론이 불투명하고(대부분 차트 패턴 + 테마 후행 추종),
선행매매 유인이 구조적으로 존재한다. **이 시스템은 이를 정보원으로 쓰지 않는다.**
다만 그들이 자주 쓰는 기법 중 검증 가능한 것(전고점 돌파, 거래량 급증)은
2.3의 이벤트 통계로 흡수해 백테스트로 진위를 가린다.

## 3. 목표가 산정 — 증권사 애널리스트의 실제 계산법

증권사 목표가는 감이 아니라 공식이다. 표준형:

```
목표주가 = 12개월 예상 EPS × 목표 PER
```

- **12개월 예상 EPS**: 매출 추정 → 마진 추정 → 이익 추정 (애널리스트의 핵심 노동)
- **목표 PER**: ① 해당 종목의 역사적 PER 밴드 ② 글로벌 피어(동종업계) 평균
  ③ 시장 대비 프리미엄/디스카운트 판단으로 결정

업종별 변형:

| 밸류에이션 도구 | 적용 업종 | 원리 |
|---|---|---|
| PER (이익 배수) | 일반 제조/서비스 | 이익의 몇 배 가치인가 |
| PBR × ROE | 은행/보험/지주 | 자본 대비 수익력 |
| EV/EBITDA | 장치산업(반도체/화학/조선) | 감가상각 왜곡 제거 |
| DCF | 현금흐름 안정(통신/유틸리티) | 미래 현금흐름 할인 |
| SOTP | 복합기업/지주사 | 사업부별 가치 합산 |

### 자동화 관점의 결론

- **완전 자동화 어려움**: EPS 추정 자체는 정성 판단(애널리스트의 일). 직접 하지 않는다.
- **자동화 가능**: ① 컨센서스 EPS·목표가를 API로 수집하고 그 **변화율**(상향/하향)을 신호로
  사용 ② 현재가와 컨센서스 목표가의 괴리율을 진입 필터로 사용
  ③ 역사적 PER 밴드 하단/상단 위치를 과열 판단에 사용
- 즉 시스템의 "목표가"는 **자체 산정이 아니라 컨센서스 + 통계적 기대수익**
  (2.3 이벤트 통계의 평균 반응폭)의 결합으로 정한다.

## 4. 손절가 산정 — 전문가들의 3가지 방식

목표가보다 손절가가 훨씬 중요하다 (목표가는 틀려도 계좌가 안 죽지만 손절 실패는 죽는다).
전문 트레이더의 손절 산정은 세 계열로 수렴한다:

### 4.1 변동성 기반 (ATR) — 퀀트/시스템 트레이딩 표준 ★ 채택

```
손절가 = 진입가 − ATR(14) × k     (k = 1.5 ~ 2.0이 일반적)
```

ATR(Average True Range)은 그 종목의 "평상시 하루 움직임 폭"이다.
삼성전자(저변동)와 코스닥 바이오(고변동)에 같은 -3% 손절을 걸면
전자는 너무 느슨하고 후자는 노이즈에 계속 털린다. ATR 배수 손절은
**종목의 성격에 비례한 손절폭**을 자동으로 만들어 주므로 자동매매에 최적.

### 4.2 기술적 근거 기반 — 재량 트레이더 방식

- 진입 근거가 소멸하는 지점: 돌파 매수라면 **돌파선 아래 복귀** 시 (우리 변동성 돌파
  전략이라면 `breakoutPrice` 하회가 논리적 손절선)
- 직전 스윙 로우(최근 저점), 주요 이동평균선, 매물대 하단

### 4.3 리스크 기반 (포지션 사이징과 결합) — 계좌 관리의 핵심 ★ 채택

방향이 반대다. "얼마에 손절할까"가 아니라 **"한 번의 실패로 계좌의 몇 %까지 잃어도
되는가(R)"를 먼저 정하고 수량을 역산**한다:

```
1R = 계좌 × 1% (허용 손실)          예: 1,000만원 × 1% = 10만원
손절폭 = 진입가 − 손절가(4.1로 산정)  예: 주당 2,000원
주문 수량 = 1R ÷ 손절폭              예: 10만원 ÷ 2,000원 = 50주
```

현재 시스템의 `ORD_QTY=1`(1주 고정)은 이 로직으로 대체되는 것이 v2 주문 수량 설계의 답이다.

**단주(端株) 규칙 — 한국 주식은 1주 미만 분할이 없다**: 역산 수량은 항상 **내림**한다
(올림은 허용 손실이 1R을 초과하게 만든다). 내림 결과가 0주이거나, 내림으로 인한 실제
리스크가 목표 1R 대비 **±20%를 벗어나면 해당 진입은 스킵**한다. 고가 종목일수록 소액
계좌에서 1% 룰이 왜곡되는데, 왜곡된 채 진입하는 것보다 진입하지 않는 것이 규칙에 충실하다.

**체결가 기준 재계산**: 손절가와 1R 검증은 신호 시점가가 아니라 **실제 체결가**로
재계산한다. 돌파 순간의 슬리피지로 진입가가 밀리면 신호 시점의 계산은 이미 틀린 값이다.
재계산 결과 실제 리스크가 1R의 +20%를 초과하면 초과분을 즉시 정리하고 기록한다.
슬리피지 자체의 억제는 시장가 대신 **지정가 분할 주문(Price Jitter — ADR-001 2.5의
기존 결정)** 으로 한다. 현행 시장가 주문(`ORD_DVSN=01`)은 Phase 2에서 전환한다.

### 4.4 손익비(Risk:Reward) 필터 — 두 층위로 나뉜다

손익비 = 기대수익폭 ÷ (진입가 − 손절가) ≥ 2.0. 단, **"기대수익폭"을 어디서 얻는지에
따라 필터가 작동하는 층위가 다르며, 이 둘을 섞으면 논리 모순이 생긴다**:

| 층위 | 대상 전략 | 기대수익폭의 출처 | 적용 방식 |
|---|---|---|---|
| **건별 사전 필터** | 이벤트 드리븐 (Phase 3d) | 과거 유사 이벤트의 D+1~D+20 반응 통계 (§2.3) | 진입 직전 `RiskRewardRule`이 건별 검사 |
| **전략 단위 관문** | 당일 변동성 돌파 | 백테스트의 평균 승리폭 ([백테스트 설계](BACKTEST-DESIGN.md)) | 건별 검사 불가·불필요 — 전략 승격 심사에서 "평균 승리폭 ÷ 평균 손절폭 ≥ 2.0"으로 검사 |

당일 청산 전략은 오늘 종가를 미리 알 수 없으므로 건별 사전 손익비가 성립하지 않는다.
여기에 가상의 목표가(저항선 등)를 세워 건별 필터를 흉내 내면 전략 자체가 변질된다 —
**당일 돌파의 손익비는 전략 통계로만 심사한다.**

### 4.5 시간 손절 (타임컷)

가격과 무관하게 "예상 시나리오가 N일 내 작동하지 않으면 철수".
현재 계획된 **15:15 타임컷**(당일 청산)이 이것의 가장 단순한 형태다.

## 5. 시스템 매핑 — 단계별 구현 목표

| 단계 | 구현 항목 | 방법론 근거 |
|---|---|---|
| **v1 (현재)** | 뉴스 키워드 감성 분류 (매매 미연동) | §1 — 정보원 중 최약체임을 인지하고 참고용으로만 |
| **Phase 2** | ATR 기반 손절 + 15:15 타임컷 + R 기반 주문 수량(단주 내림·체결가 재계산) + 지정가 분할 주문(Price Jitter) + 필터 훅 4종(기본 OFF — [백테스트 §3.3](BACKTEST-DESIGN.md)) | §4.1, 4.3, 4.5 — 종목 발굴보다 **출구/사이징이 먼저** |
| **Phase 3a** | DART 공시 수집(뉴스보다 상위 정보원) + 이벤트 택소노미 분류 (LLM: 뉴스→`{유형,방향,강도,대상}` 구조화) | §1 |
| **Phase 3b** | 이벤트→밸류체인 매핑 테이블 + 재무 필터(탈락용) | §2.1, 2.2 |
| **Phase 3c** | 이벤트 유형별 과거 주가 반응 백테스트 → 기대수익 통계 | §2.3 |
| **Phase 3d** | 손익비 필터(`RiskRewardRule`) — 기대수익(3c) vs 손절폭(ATR) ≥ 2:1 | §3, 4.4 |
| **Phase 4** | 팩터 스코어링 + Capacity Scaling (ADR-002) | §2.4 |

**설계 원칙 4가지**

1. **출구가 입구보다 먼저다**: 어떤 종목 발굴 로직을 붙이든, 손절(ATR)·사이징(R)·타임컷이
   먼저 완성되어야 한다. 발굴이 틀려도 출구가 있으면 살고, 반대는 죽는다.
2. **백테스트 없는 규칙은 채택하지 않는다**: 이벤트→반응 통계(3c)로 검증된 이벤트 유형만
   실매매 신호로 승격한다. 검증 전 유형은 `OpportunityCostLogger`처럼 기록만 한다.
   백테스트 인프라 자체의 설계는 [BACKTEST-DESIGN.md](BACKTEST-DESIGN.md) 참고.
3. **정성 판단은 자동화하지 않는다**: EPS 추정·DCF는 컨센서스 데이터 수집으로 대체하고,
   시스템은 그 **변화율과 괴리율**만 신호로 쓴다.
4. **LLM은 후보 생성까지만, 절대 최종 게이트가 아니다**: LLM의 이벤트 분류(3a)는
   후보 종목을 "제안"할 뿐이며, 주문에 이르려면 반드시 정량 필터(재무 필터 → 백테스트
   검증된 이벤트 유형 → 손익비 → RiskEngine)를 전부 통과해야 한다. 이유:
   ① 뉴스 본문은 신뢰할 수 없는 입력이다 — 광고·조작성 텍스트가 분류를 왜곡하는
   프롬프트 인젝션이 가능하므로, LLM 입력은 데이터로만 취급하고 그 출력이 직접
   매매를 트리거하는 경로를 만들지 않는다. ② 환각·오분류율이 0이 아니다.
   ③ 호출 비용·지연이 1초 루프와 양립하지 않는다 (LLM 분석은 비동기 배치로만).
